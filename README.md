# HealthGPT – A Tiny GPT Built from Scratch

## About the Project
HealthGPT is a small GPT-style language model built using Python and PyTorch. 
It generates general care information based on disease names.

## Technologies Used
- Python
- PyTorch
- Google Colab
- BPE Tokenizer
- NumPy
- Matplotlib

## Model Architecture
- 4 Transformer Layers
- 4 Attention Heads
- 128 Embedding Dimensions
- 128 Token Context Length
- AdamW Optimizer

## Features
- Disease name input
- Care information generation
- Custom disease dataset support
- Model training and validation
- Loss curve visualization

## How to Run
1. Download the notebook.
2. Open it using Google Colab.
3. Select T4 GPU (recommended).
4. Run all cells.
5. Enter a disease name to generate care information.
